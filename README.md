# FASAD MASTER

Общая система менеджера и цеха: заказы, производство, склад, рейсы, общий чат, планы и отчёты в м². Красно-тёмное оформление под логотип FASAD MASTER; исходное изображение логотипа сохранено без изменений.

## Что реализовано

- Вход через личный аккаунт ChatGPT. Владелец определяется по серверному параметру OWNER_EMAIL.
- Приглашения сотрудников на 7 дней с ролью менеджера или цеха; отзыв доступа.
- Имена и фотографии сотрудников, карточки клиентов и изделий, сроки, приоритеты, архив и печатные ярлыки.
- Частичная заливка → выдержка → готовность → отгрузка. Брак учитывается отдельно.
- Несколько рейсов на один заказ: отдельные дата, количество, водитель, машина и адрес. Отдельно видны объём заказа, сколько ушло и сколько осталось клиенту. Отменённый рейс остаётся в истории, его номер не используется повторно.
- Оплата заказа: «Не оплачен», «Частично оплачен», «Оплачен» с комментарием менеджера. Это ручная отметка, не банковская операция и не денежная бухгалтерия; суммы долга не вычисляются.
- Общий чат с именами сотрудников и ссылками на заказы. Доступ только участникам команды, обновления каждые 10 секунд. Хранятся последние 3000 сообщений.
- Планы на выбранную дату: задача, ответственный, заказ, подробности и отметка выполнения. Менеджер или владелец создаёт/отменяет задачи. Цех отмечает свои задачи или задачи всей команды. Выполнение задачи не заменяет фактический учёт заливки/рейса.
- Начальные складские остатки и резервирование готовой продукции под заказ с совпадающим изделием и цветом.
- Исправление ошибочных производственных операций владельцем с сохранением причины и истории.
- Отчёты за период, диаграмма, CSV для Excel, журнал действий.
- Общие данные в D1, фотографии в R2. Проверка обновлений каждые 10 секунд.
- Сохранение с проверкой версии, защита от повторной отправки и серверные проверки ролей.
- Демонстрационный режим изолирован от настоящей базы.
- Подготовлена установка веб-приложения на телефон/компьютер: manifest, значки, отдельное окно, кнопка установки или инструкция для браузера. Установка доступна только после HTTPS-публикации; в демонстрации показано пояснение. На опубликованной версии установка и вход из отдельного окна ещё не проверены.

## Как раздать сотрудникам приложение

Один HTML или ZIP не создаёт общую базу. Сначала публикуется сервер и появляется постоянная HTTPS-ссылка. Затем владелец передаёт сотрудникам эту ссылку и код приглашения. Сотрудники входят через ChatGPT и могут установить сайт как приложение через меню Chrome/Edge (компьютер или Android) либо Safari → «Поделиться» → «На экран Домой» (iPhone).

Установленная версия подключается к той же серверной базе, поэтому отдельные APK/EXE для разных устройств не требуются. Данные сверяются каждые 10 секунд, пока приложение открыто, и при возвращении к нему. Для сохранения нужен интернет. Автономная очередь изменений и фоновая синхронизация при закрытом приложении не реализованы. Защищённые ответы и фото не кешируются сервис-воркером; сервис-воркер не устанавливается.

## Состояние поставки

Интерфейс и серверная логика подготовлены. TypeScript проверен. 61 проверка доступа, расчётов, конкурентных операций, резервов, исправлений, двух рейсов, оплаты, чата, планов и обновления старых данных прошла на локальном SQLite с имитацией окружения Cloudflare. Интерфейс проверен в браузере.

Продукционная сборка, загрузка в Sites и вход в опубликованную версию не завершены: передача данных инструменту публикации заблокирована политикой среды. Не считать эту поставку уже работающим онлайн-сервисом.

`FASAD-MASTER-preview.html` рядом с архивом — автономный предпросмотр с примерами. Он не сохраняет реальные заказы и не синхронизирует пользователей.

## Разработка

Node.js 22.13+ (для локальных тестов рекомендуется Node.js 24), pnpm 11.25.0.

    pnpm install --frozen-lockfile
    pnpm dev
    pnpm build

Используется Vinext / React и штатная интеграция Sites. Сохраняйте интеграцию `sites()` в vite.config.ts. В Windows среда должна разрешать служебные каналы дочерних процессов сборки.

## Публикация через Sites

Сайт уже зарегистрирован; используйте существующий `project_id` из `.openai/hosting.json`. Не создавайте новый сайт вместо него.

Bindings: DB (D1) и BUCKET (R2). Миграция: drizzle/0000_workspace.sql. SQL и Drizzle metadata включены. При публикации Sites применяет миграции.

В параметрах Sites уже настроен секрет OWNER_EMAIL. Значение не хранится в исходниках. В другой среде задайте его отдельно. При локальной разработке можно использовать игнорируемый .dev.vars с адресом локальной тестовой учётной записи.

Публикуйте через штатный source workflow, затем save/deploy. Аудитория Sites пока остаётся private/custom. Для работы приглашённых сотрудников требуется публичный экран входа сайта (access_mode=public); реальные записи доступны только членам команды после проверки ChatGPT identity и приглашения. Не открывайте API анонимным пользователям.

## Учёт

Количество хранится целым числом сотых м². Заливка не увеличивает готовый склад. Склад меняется при готовности, отгрузке и начальном остатке. Резервирование переносит количество между свободным складом и заказом без изменения общего остатка. Каждая карточка заказа описывает одно изделие и цвет; разные изделия оформляйте отдельными карточками.

Начальные остатки и операции резервирования не отменяются обычной отменой производственной операции. Производственные операции с зависимыми действиями исправляются в обратном порядке. Журнал действий хранит последние 2000 событий; производственные движения сохраняются в полном объёме. Система рассчитана на небольшую команду; данные рабочего пространства хранятся одним документом с атомарной проверкой версии.
